# BML CS&IT Portal

Corporate website and internal IT operations portal for Bharat Minerals Limited.

## Features

- Corporate Website
- CS&IT Department Portal
- Document Management
- Asset Management
- Ticket Management
- Audit Logs
- Role-Based Access
- Dashboard Analytics

## Tech Stack

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- LocalStorage Authentication
